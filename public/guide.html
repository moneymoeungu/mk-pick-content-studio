  • 수치·날짜 형광펜 팩트체크: 노란색 형광펜 문장(금액·일자·수량)을 확인 후 클릭하여 초록색(✓ 확인 완료)으로 전환

4
상단 카드 — STEP 2 : 5대 콘텐츠 유형 선택 (01~05)
키워드를 입력하면 가장 알맞은 콘텐츠 유형이 자동으로 주황색 활성화(✓ 현재 선택됨)됩니다. 다른 유형으로 쓰고 싶다면 원하는 유형 카드를 직접 클릭해 바꿀 수 있습니다.
5

3
우측 상단 ↻ 실시간 트렌드 새로고침 버튼

4
과거 유행어 자동 배제 필터 적용
이미 유행이 지난 과거 키워드(예: 탕후루, 두바이 초콜릿 등 회고성 기사 키워드)는 자동 필터링하고 최근 7일 이내 보도·쇼츠 데이터만 선별해 보여줍니다.

👁️ 실제 기사 미리보기 화면에서의 형광펜 팩트체크 & 편집 복귀
미리보기 화면에서는 실제 독자가 읽는 기사 레이아웃 그대로 전체 흐름을 점검할 수 있습니다. 본문 속 노란색 형광펜 문장(미확인 수치·날짜)을 직접 클릭하면 즉시 초록색(팩트 확인 완료)으로 전환되며, 우측 상단 ✏️ 편집 화면으로 돌아가기를 누르면 언제든 다시 수정할 수 있습니다.
Q1
실수로 브라우저를 닫거나 새로고침(F5)을 누르면 작성하던 기사가 날아가나요?
절대 날아가지 않습니다. 글자를 수정할 때마다 실시간으로 자동 저장되며, 홈 화면 하단의 📂 최근 작업한 기사 탭에서 언제든 이어서 편집할 수 있습니다.
Q2
팀원 여러 명이 공유 링크에 접속하거나 새로고침하면 API 비용이 계속 나가나요?
나가지 않습니다(0원). 30분 스마트 캐시가 작동하므로 단순 접속이나 F5 새로고침 시에는 캐시된 트렌드를 즉시 보여주어 API 요금이 소진되지 않습니다.
Q3
복사한 기사를 사내 CMS에 붙여넣을 때 서식이 깨지지 않나요?
우측 상단 📋 CMS 붙여넣기용 전체 복사 버튼은 불필요한 HTML 태그 없이 매경 CMS 표준 줄바꿈·소제목(■)·요약표·FAQ 순수 텍스트 포맷으로 복사하므로, CMS 본문창에 Ctrl + V만 하시면 깔끔하게 등록됩니다!
